# Mynx 功能验收矩阵

每次发布候选版本执行；结果需记录应用版本、操作系统、R 版本及测试数据 SHA-256。科研结果比较字段和值，不比较含时间戳的 xlsx 二进制。

| 区域 | 正常路径 | 异常/取消路径 | 验收结果 |
|---|---|---|---|
| qPCR | Excel 导入 → 转换 → 内参/对照计算 → 保存 → 图表 | 缺列、缺失 Ct、重复数不符、保存失败 | 待执行 |
| RNA-seq | CSV/TSV/featureCounts 导入 → 分组 → DEG → 结果目录 → 单图重绘 | 文件不可读、R 缺包、批次混淆、取消、切换历史目录 | 待执行 |
| 科研绘图 | 示例数据 → 字段映射 → 五种输出格式 → 参数清单 | 缺字段、缺 R、缺包、取消、重复生成 | 待执行 |
| TIFF | 单页/多页、Unicode 路径、质量和水印 | 损坏文件、无转换工具、水印不可用、取消 | 待执行 |
| 搜索 | 新窗口、导航、标签、地址栏、缩放 | 无效 URL、关闭标签、远程页面异常 | 待执行 |
| 通用 | 主题、语言、拖放、更新提示 | 权限拒绝、网络超时、窗口关闭 | 待执行 |
| 安装器 | 首次安装、升级、快捷方式、卸载 | 权限不足、进程占用、资源缺失、回滚 | 待执行 |

## 发布门槛

- 主应用与安装器 TypeScript、Rust 检查通过。
- `npm test`、`npm run lint`、图表契约检查通过。
- Windows 和 macOS 各完成一次真实任务取消和一次历史结果加载。
- 安装后逐项确认 R 引擎、图表模板和示例资源可访问。
- 任何科学数值变化必须有明确的算法变更说明和人工复核。
