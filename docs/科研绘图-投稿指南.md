# 科研绘图：投稿前使用指南

## 推荐流程

1. 导入 CSV、TSV 或 Excel；也可以先下载当前模板的示例数据。
2. 选择图表模板，确认 X、Y、分组和大小字段。
3. 在“论文规格”中选择单栏、双栏或自定义尺寸。
4. 调整主题、字体、配色、图例、网格、标题和统计标注。
5. 投稿位图选择 TIFF 并使用至少 300 DPI；需要后期排版时选择 SVG、PDF 或 EPS。
6. 生成后检查预览，并导出“图表 + 参数”结果包。

## 结果包内容

结果包包含图表文件、参数 JSON、模板清单、实际使用的 R 脚本、默认参数和中文说明。参数文件记录模板来源、源文件路径、尺寸、DPI、格式和全部外观设置，便于复核和再次生成。

## 数据要求

- 第一行应为字段名，字段名不能重复。
- 分类字段可使用文字；数值字段应保存为真正的数字，不要把千位分隔符或单位混在单元格里。
- 生成前会检查空表、空字段、字段映射和数值列；错误会在运行日志中说明。

## R 环境和依赖

只有点击生成时才会检查 R。模板所需 R 包默认不下载；勾选“允许按需安装”后，缺少的包才会从 CRAN 安装。未安装 R 时，可以在页面中先安装或按提示手动安装。

图表模板和示例来源见 [R Graph Gallery](https://r-graph-gallery.com/)。具体来源链接也会写入结果参数文件。
