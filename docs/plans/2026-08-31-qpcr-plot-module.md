# qPCR 模块 3：柱状图与热图实施计划

**状态：** 核心版本已实施；高级功能仍按后续批次补齐。

**Goal:** 在现有模块 1、2 下方增加独立的“3 绘制柱状图和热图”，通过上传数据和可视化控件完成绘图，无需编辑 R。

**Architecture:** 模块 3 独立管理输入、工作表、绘图参数、运行状态和输出结果；只复用文件读取、R 定位、路径处理等基础能力。新增专用 R 入口，以 JSON 传递参数，分别调用柱状图和热图函数，不改动模块 2 的 Excel 内嵌图生成路径。

**Tech Stack:** React、TypeScript、ExcelJS、Tauri、本地 R、ggplot2、ComplexHeatmap、circlize；统计依赖按实际移植需求确定。

## 一、依据与边界

- 已检查 `src/pages/qPCR/QpcrPage.tsx`：模块 1、2 宽屏并排；模块 2 完成计算后保存工作簿并生成 Excel 原生图表。
- 已检查 `src/lib/qpcr-calculate.ts`：汇总表包含 Gene、Group_Name、Repeat1…N、Average、Stdev 等列，可作为模块 3 的输入。
- 参考脚本：用户提供的 `qpcr_barplot_only 4.0.R`（内部标题 v7.0）和 `heatmap_complex.r`，仅作为实现参考，不执行原脚本，不修改原文件。
- 不照搬脚本自动扫描当前目录、写回脚本目录或写死的实验基因及对照组。批量处理限用户明确选择的文件或目录。
- 本次不实现功能、不安装依赖、不打包、不提交或发布。

## 二、方案选择

1. **推荐：独立界面 + 专用 qPCR R 绘图入口。** 能完整移植参考图样，隔离已有计算流程，支持复杂热图、统计标注和批量导出。
2. 扩展模块 2 的 Excel 图表：新增依赖少，但无法完整承载 ComplexHeatmap 和参考图样，且与用户要求的独立上传不符。
3. 直接套用通用绘图工作台：可复用部分控件，但现有通用参数不足以表达基因比较对、功能分组及独立运行状态；只复用基础设施，不强行套模板。

## 三、界面与交互

保持顶部原文件区和模块 1、2 不变，下方新增全宽卡片：

```text
原数据文件选择区
[1 数据转换]                 [2 qPCR 计算]
[3 绘制柱状图和热图                         ]
  独立上传区：选择文件 / 拖入文件 / 清空 / 下载模板
  工作表选择 → 列映射 → 数据预览与校验
  图形选择：[柱状图] [热图]（可以同时勾选）
  参数页签：[通用设置] [柱状图] [热图] [统计] [导出]
  常用设置直接显示，细节放在可展开的高级设置中
  输出目录 / [预览] [运行绘图] [取消] [恢复默认]
  进度、警告、预览图库、结果文件、打开输出目录
```

- 所有自定义项用按钮、开关、下拉框、颜色选择器、数字框、排序列表或可编辑表格实现，不要求用户写代码。
- 模块 3 不依赖模块 1、2 是否运行；更换或清空任何一边的数据，不影响另一边。
- 模块 3 不自动使用模块 2 的内存工作簿；用户可自行上传模块 2 保存的结果文件。
- 两个上传区的拖放命中范围独立；模块 3 使用自身进度和取消控制，避免复用全页遮罩和通用图表运行器的全局进程状态。
- 只选择一种图时，另一种图的必填项不阻止运行。批量模式以文件为单位展示状态，单个失败不掩盖其余结果。

## 四、输入数据规则

- 优先支持 xlsx，并新增 CSV；xls 只有在确认读取链路完整支持后才对外宣称支持，不能只增加扩展名过滤。
- 自动识别并允许手动映射 Gene、Group_Name、Average、Stdev、Repeat1…N；重复列提供多选，不能固定为 3 个。
- 模块 2 生成的 Summary_All_Genes、Summary_Best_Replicates、Summary_Outlier_Removed 均可选择，用户明确决定使用哪份数据。
- 热图最少需要 Gene、Group_Name、Average。柱状图需要均值；使用上传 SD 时需要 Stdev；无误差模式允许缺少 Stdev。散点与统计需要真实 Repeat 值，不从均值、标准差伪造重复值。
- 数据来源可选“使用表中均值/SD”（默认）或“从重复值重算均值/SD”；如果二者不一致，提示用户，不静默覆盖。
- 校验空表、空基因/组名、非有限数值、负 SD、重复 Gene×Group 行、缺少组别、无效比较对象；错误定位到行和列。
- 重复 Gene×Group 默认报错，避免热图构造列表矩阵；缺失组合显示缺失颜色并提示，不默认填零。
- 常量基因的行 Z-score 为 0；缺失数据保持缺失；单组及不足有效值场景给出明确提示。
- 分组名称换行只改变显示标签，排序、比较和颜色映射始终使用原始组名。

## 五、参考参数到界面控件的完整映射

### 5.1 柱状图顶部配置

| 参考参数 | 控件 |
|---|---|
| BATCH_MODE、INPUT_FILE | 单文件/批量切换、文件选择、可选目录及待处理列表 |
| OUTPUT_DPI | 分辨率预设 + 自定义数字框 |
| AUTO_SIZE、CUSTOM_W、CUSTOM_H | 自动尺寸开关、宽高、单位选择 |
| BAR_FILL、BAR_BORDER、BAR_BORDER_W | 填充色、边框开关/颜色/线宽 |
| ERR_W、ERR_CAP、ERR_COL | 误差棒线宽、端帽宽度、颜色 |
| AXIS_W、TICK_LEN | 坐标轴线宽、刻度线长度 |
| X_ANGLE、X_HJUST、X_VJUST | 标签角度、水平/垂直对齐 |
| WRAP_PLUS、SHOW_XTICK | 加号换行、显示组名开关 |
| TITLE_SZ、YLAB_SZ、YTICK_SZ、XTICK_SZ、TITLE_VJ | 标题与各轴字号、标题垂直偏移 |
| SHOW_POINTS | 显示重复散点 |
| ENABLE_SIG、SHOW_SIG | 运行统计、显示统计标注两个独立开关 |
| SIG_MODE | 自定义、对第一组、对最后一组、对指定对照、全部两两、相邻六种模式 |
| CONTROL_GROUP | 根据输入数据生成对照组选项 |
| SIG_TEST | 自动、Welch t、Wilcoxon、ANOVA+Tukey、Kruskal-Wallis+逐对 Wilcoxon |
| P_ADJ | none、Bonferroni、Holm、BH；已由 Tukey 校正时禁用重复校正 |
| LABEL_STYLE、SHOW_NS | 星号/P 值/两者、显示 ns |
| SIG_FILE | 统计文件名及输出开关 |
| BK_W、BK_TXT、BK_LAB_GAP、BK_STEP | 括号线宽、文字大小、文字偏移、层间距 |
| PAIRS | 增删比较行：全部/指定基因、对照组、处理组；支持一对多展开并显示最终比较清单 |

### 5.3 脚本内部外观常量与常用扩展

**通用：** 基因/组筛选、排序与显示名称；字体、加粗/斜体、标题显示、背景/透明背景、边距、图例显示/位置/字号；配置保存、加载和恢复参考预设。

**柱状图：**

- 单色或分组配色、色盲友好预设；自动/手动柱宽、柱间距。
- SD/SEM/无误差棒；单侧向上或双侧误差棒。SEM 仅在有有效重复数时提供，显示计算依据。
- 散点大小、颜色、透明度、形状、抖动宽度；固定抖动种子确保重画一致。
- X/Y 轴标题、参考基因文本，移除硬编码的 TBP；自动无法确定归一化依据时默认使用“相对表达量”。
- Y 轴范围、刻度间隔/数量、数字小数位、科学计数法自动/开/关、线性/log10；非正数的 log10 明确阻止，不偷偷加常数。
- 标题位置/字体样式、网格、坐标轴颜色、显著性括号颜色/下垂长度/起始高度；自动范围应包含散点、误差棒和标注。
- 每基因单独导出及多基因拼图，拼图列数与统一/独立 Y 轴选择。

**热图：**

- 行 Z-score（参考默认）、列 Z-score、原始均值、log2 转换；log2 的伪计数需显式配置并记录。
- 低/中/高三色、预设配色/反转、自动/手动色阶、缺失值颜色；色阶裁剪仅影响颜色，不修改导出矩阵。
- 格内显示原始均值（参考默认）/变换后值、小数位、字号/加粗、自动对比文字颜色或手动文字颜色。
- 行列名的显示/位置/字体/字号/角度；单元格边框颜色和线宽、行列间距、注释条宽度。
- 自动行/列层次聚类分别开关，距离及连接方法选择；默认均关闭以保留原表顺序。
- 手动功能分组与自动聚类并存时明确顺序规则：先按功能分组排列，再可选组内聚类；启用自动聚类时禁用冲突的手动排序控件。
- 未分组基因默认保留为“未分组”；可选排除并在运行前列出被排除项，不照搬脚本的默认删除行为。
- 色阶图例与功能分组图例分别配置标题、字号、位置、尺寸；支持原脚本的刻度文字格式、图例项尺寸和画布边距。

## 六、统计与脚本移植注意事项

- 参考脚本注释与实际实现有差异：非参数流程实际是 Kruskal-Wallis + 逐对 Wilcoxon，不能在界面标成 Dunn。
- 参考脚本会在部分比较模式下把手动指定的方法改为 t 检验；新模块不静默替换。自动模式显示实际方法，手动选项不兼容时在运行前说明原因。
- 原始 P、校正 P、整体检验 P 分列；Tukey 返回的已校正 P 不冒充原始 P。
- 明确校正范围（默认每基因的本次比较集合；Tukey 按其实际比较族记录），不让过滤显示改变统计集合。
- 样本不足、检验失败不生成假 P 值或误导性星号；保留图像并显示统计失败原因，可重新运行。
- 引导用户明确 Repeat 是技术重复还是独立生物重复；不自动把技术重复当成独立生物样本进行推断。
- 绘图与统计读同一份已校验的数据快照；不添加自动剔除重复值的隐含步骤。

## 八、完成标准

1. 模块 3 位于模块 1、2 下方，不执行前两步也能上传数据并出图。
2. 支持单独或同时生成柱状图和热图，独立选择数据工作表。
3. 两份参考代码的自定义项全部有可用控件，另有常见外观、排序、导出和预设功能。
4. 输入源文件及模块 1、2 状态不被模块 3 修改；原自动 Excel 图表流程保持不变。
5. 统计、缺失数据、分组筛选及错误状态透明可见，结果可追溯到输入和配置。
6. 本地运行、取消、预览、导出及安装资源定位验证通过；没有 R 时给出清楚提示。
