# qPCR 第 3 步：柱状图与热图工作台

## 目标

在现有 qPCR 数据转换、相对表达量计算之后，增加独立的第 3 步绘图卡片。用户可以导入已经计算好的 qPCR Excel，选择柱状图或热图模板，通过按钮完成论文绘图常用设置，并运行 R 脚本导出图形与统计汇总。

## 交互设计

- 顶部横向文件工具栏：输入 Excel、工作表、输出目录、设置 JSON 导入/导出、运行。
- 左侧模板：柱状图、热图两个模板按钮，显示模板特点。
- 右侧参数：按图类型显示尺寸、分辨率、格式、配色、坐标轴、误差棒、散点、科学计数法、显著性检验、Z-score、聚类和格内数值等控件。
- 预览：在浏览器内用 SVG 生成轻量预览；正式运行由 R 生成投稿质量文件。
- 结果：导出图形、统计分析 CSV 和可复现 JSON 设置清单，并将运行日志显示在卡片内。

## 数据流与统计规则

1. ExcelJS 读取用户选定的工作表，识别 `Gene`、`Group_Name`、`Average`、`Stdev` 与 `Repeat*` 列。
2. 运行时将 UI 配置写入临时 JSON，调用资源目录中的 qPCR 专用 R runner。
3. 柱状图沿用参考脚本的科学计数法判定：均值加标准差全部落在 `0.0` 显示范围，或最大值大于等于 100 时按最大数量级缩放。
4. 显著性比较支持 custom、vs_first、vs_last、vs_control、all_pairwise、adjacent；自动检验遵循两组/计划比较用 Welch t-test，多组用 ANOVA + Tukey，非参数模式用 Wilcoxon/Kruskal-Wallis，并按 none、Holm、Bonferroni、BH 校正。
5. 热图按基因计算行 Z-score，支持行/列聚类、功能聚类预设、显示原始均值和颜色范围控制。

## 错误处理与验证

- 未选择输入文件或输出目录时禁用运行按钮。
- 缺少必需列、无有效数值或 R 不可用时显示明确错误，不影响前两步。
- 设置导入仅接受已知字段并回退到默认值。
- 验证包括 TypeScript 构建、ESLint、现有测试和手动确认两种模板、文件工具栏与窄屏布局。
